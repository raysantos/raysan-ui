raysan-ui

The shared foundation for every Raysan Designs project: Material Design 3 color roles, the Sofia Sans type scale, shape, motion, a handful of components and the sun/moon theme toggle. Taken directly from raysandesigns.com.

Use it

Start new projects from the template folder, or paste this into any page's <head>. Pinning to @0.1 picks up fixes but never breaking changes.

Color

M3 color roles. Pair every container with its "on" color. Toggle the theme to see the dark palette, which is designed separately rather than inverted.

Brand accents

Type

Sofia Sans for display, headlines, titles and labels. Google Sans Text for body copy. Use as font: var(--headline-m) or the matching class.

Shape

Corner radii. Cards use extra-large (30px), buttons and chips are fully rounded.

Buttons

.btn plus a style. Add a Material Symbol in a .ms span for a leading icon, or .trail for a trailing one.

Largearrow_forward

Chips

Tags for tools, statuses and filters. Green is the brand default; .chip-neutral for quieter lists.

Cards

Outlined by default, .card-filled for a quieter surface. Make the whole card a link with <a class="card">.

Brand a project

Need Porsche red for Garage Log or Anycubic blue for the resin matrix? Load a small theme file after raysan-ui and override only the tokens that change. Starter: themes/example.css.

:root {
  --md-primary: #8c0000;
  --md-primary-container: #f7dcdc;
  --md-on-primary-container: #5c0000;
  --rd-brand-bar: linear-gradient(90deg, #8c0000, #d5001c);
}
:root[data-theme="dark"] {
  --md-primary: #ffb4a9;
}
