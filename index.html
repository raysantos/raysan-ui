Design system · v0.1

raysan-ui guidelines

How every Raysan Designs site and app looks, reads and behaves. Built on Material Design 3, tuned to the raysandesigns.com look: calm surfaces, outlined cards, a coral-to-peach brand bar and a designed dark mode.

01

Principles

Four rules that settle most design decisions before they come up.

self_improvement

Calm over busy

Flat surfaces, thin outlines, slow subtle motion. Color is saved for meaning: actions, status, the brand bar.

token

Tokens, not values

Every color, size and radius comes from a token. If a value isn't a token, it's either a new token or a mistake.

dark_mode

Dark is designed

Dark mode has its own palette, not an inversion. Use tokens and it works for free; check it before shipping.

accessibility_new

Accessible by default

Readable contrast, visible focus, keyboard reachable, reduced motion respected. Not a later pass.

02

Brand

Four brand elements carry the identity. Use them sparingly so they stay special.

Raysan

Brand mark

Gradient tile with a surface-colored notch. Pair with the project name in title-l. Use .brand + .brand-mark.

Brand bar

Static 4px coral-to-peach line. Use it where a page has no scrolling header, like a single-screen tool or an email. Token: --rd-brand-bar.

Scroll progress

The hero gradient along the bottom of the top app bar, growing left to right as you read, with the colors slowly drifting. The default header for every page; scroll this one to see it. Add .scroll-progress inside the header and load scroll-progress.js.

Hero gradient

Coral, peach, sky, teal. Hero moments and case study covers only, never behind body text. Token: --rd-hero-grad.

04

Typography

Two families. Sizes follow a classic scale (12 · 14 · 16 · 18 · 21 · 24 · 36 · 48 · 72) with line heights on an 8px rhythm.

AaSofia Sans

Display, headlines, titles, labels, buttons. Token: --md-font

AaGoogle Sans Text

Body copy and long reading. Token: --md-font-body

Use the role, not the size: font: var(--title-m) in CSS or class="title-m" in HTML. Display sizes step down automatically on phones.

06

Shape & elevation

Soft and friendly. Cards use extra-large corners; anything you press is fully rounded. The system is flat: no drop shadows, outlines do the structural work.

--shape-xlCards

07

Spacing & layout

Spacing moves in 4px steps, mostly 8, 12, 16, 24, 32 and 48. Page margins and grid gaps grow with the screen.

ScreenWidth--margin--gap
Compact (phone)under 600px16px16px
Medium (tablet)600–839px24px20px
Expanded (desktop)840px and up32px20px

Content sits in .wrap (max 1120px, centered). Use .stack for vertical rhythm and .row for inline groups.

08

Motion

Motion explains a change; it never decorates. Short for small things, longer for big moves, always the emphasized easing. Everything stops when the visitor asks for reduced motion.

TokenValueUse for
--dur-s150msHover, state layers, color changes
--dur-m300msTheme fade, panels, small reveals
--dur-l500msPage-level moves, large reveals
--ease-emphcubic-bezier(.2, 0, 0, 1)Everything: fast start, gentle landing

10

Theming a project

A project can wear its own brand (Porsche red for Garage Log, Anycubic blue for the resin matrix) without forking the system. Load a small theme file after raysan-ui and override only the tokens that change.

/* garage-log/theme.css */
:root {
  --md-primary: #8c0000;
  --md-primary-container: #f7dcdc;
  --md-on-primary-container: #5c0000;
  --rd-brand-bar: linear-gradient(90deg,#8c0000,#d5001c);
}
:root[data-theme="dark"] {
  --md-primary: #ffb4a9;
  --md-primary-container: #5c1a12;
  --md-on-primary-container: #ffdad5;
}
OverrideColor roles, fonts, the brand bar, corner radii.
KeepComponent classes, spacing, motion and the theme toggle. They adapt to whatever tokens you set.
PromoteIf two projects need the same new piece, it moves into raysan-ui.

11

Accessibility

Check these before every launch. Most are already handled if you stick to tokens and components.

  • check_circleText meets 4.5:1 contrast (3:1 for 24px+ or bold 18px+). The color badges above show it live.
  • check_circleEverything works with a keyboard and the focus ring is visible.
  • check_circleIcon-only buttons have an aria-label; decorative icons have aria-hidden="true".
  • check_circleEvery form field has a visible label and errors explain how to fix them.
  • check_circleImages have alt text (empty alt="" if decorative).
  • check_circlePage works at phone width with no sideways scrolling.
  • check_circleChecked in both light and dark.
  • check_circleAnimations stop under reduced motion (built into base.css).
